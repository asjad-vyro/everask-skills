# Reference list styles

Patterns for the six styles this skill reformats to. Angle brackets are fields taken from the user's entry; never fill one that the entry does not give (write the missing-field placeholder from SKILL.md instead). A part shown with "only if given" is left out, with no placeholder, when the entry lacks it. Italics are written with asterisks. Keep the user's page numbers as given, with the dash the style shows.

Authorities: APA Publication Manual, 7th edition; MLA Handbook, 9th edition; Chicago Manual of Style, 18th edition (2024), author-date system; Cite Them Right (Harvard), 13th edition; IEEE Reference Guide; NLM "Citing Medicine" and the ICMJE/NLM sample references (Vancouver).

If the user gives their own style guide, a journal's instructions or another edition, those win over this file. Where this file does not cover what they need (another source type, another edition's rule), keep that part as the user gave it and say so in the problems table.

## APA 7th edition (default)

Reference list headed "References", alphabetical by first author's surname, then year; hanging indent.

- Journal article: `<Surname>, <I. I.>, & <Surname>, <I. I.> (<Year>). <Article title, sentence case>. *<Journal Title, Title Case>*, *<volume>*(<issue>), <first page>–<last page>. https://doi.org/<doi>` (issue and DOI only if given; no full stop after the DOI).
- Book: `<Surname>, <I. I.> (<Year>). *<Book title, sentence case>* (<edition as an ordinal> ed.). <Publisher>. https://doi.org/<doi>` (edition only if given and not the first; DOI only if given; no place of publication).
- Chapter in an edited book: `<Surname>, <I. I.> (<Year>). <Chapter title, sentence case>. In <I. I. Surname> (Ed.), *<Book title, sentence case>* (pp. <first>–<last>). <Publisher>.` ("Eds." for two or more editors.)
- Web page: `<Author written as in a journal entry, or the organisation's name followed by a full stop> (<Year>, <Month> <Day>). *<Page title>*. <Site name, only if different from the author>. <URL>`
- `(n.d.)` only when the work itself has no date. A year missing from the user's entry is the placeholder `[year missing]`, never "n.d.". Same author and same year: add a, b after the year (2020a, 2020b), ordered by title.
- Authors: list up to 20; for 21 or more, the first 19, an ellipsis, then the final author. With two or more authors, an ampersand (&) goes before the last one, after a comma.
- In-text: (Surname, Year); two authors (Surname & Surname, Year); three or more (Surname et al., Year); narrative Surname and Surname (Year); several sources (Surname, Year; Surname, Year), in alphabetical order.
- Sentence case: lower-case the title except its first word, the first word after a colon, proper nouns and acronyms. If unsure whether a word is a proper noun, leave it as the user wrote it.

## MLA 9th edition

List headed "Works Cited", alphabetical by first author's surname, hanging indent. In-text citations give author and page, not year.

- Journal article: `<Surname>, <First name>, and <First name> <Surname>. "<Article Title in Title Case>." *<Journal Title>*, vol. <n>, no. <n>, <Year>, pp. <first>-<last>. https://doi.org/<doi>.` (DOI or URL only if given. If the entry names a database, put `*<Database>*, ` before the DOI or URL.)
- Book: `<Surname>, <First name>. *<Book Title in Title Case>*. <Publisher>, <Year>.`
- Authors: one author reversed; two authors, the first reversed and the second in normal order, joined by "and"; three or more, the first author reversed followed by ", et al.".
- Web page: `<Author>. "<Page Title>." *<Website>*, <Publisher, only if different from the website>, <Day Month Year>, <URL>.`
- One page is `p. <n>`; a range is `pp. <first>-<last>`.
- In-text: (Surname 45); two authors (Surname and Surname 45); three or more (Surname et al. 45). Without a page number, (Surname).
- Use full first names where the entry gives them; if it has only initials, keep the initials.

## Chicago author-date (18th edition)

List headed "References", alphabetical, hanging indent. The year follows the author.

- Journal article: `<Surname>, <First name>, and <First name> <Surname>. <Year>. "<Article Title in Headline Case>." *<Journal Title>* <volume> (<issue>): <first>–<last>. https://doi.org/<doi>.` (issue and DOI only if given.)
- Book: `<Surname>, <First name>. <Year>. *<Book Title in Headline Case>*. <Publisher>.` The 18th edition no longer requires a place of publication; leave it out.
- Authors in the reference list: list up to six; for more than six, list the first three followed by "et al.".
- In-text: (Surname Year) with no comma, and a page after a comma: (Surname Year, 45). Two authors: (Surname and Surname Year). Three or more: (Surname et al. Year).
- Only if the user asks for the 17th edition: list up to ten authors, and for more than ten the first seven followed by "et al."; in the text name up to three authors, and use "et al." for four or more; give "<Place>: <Publisher>" when the entry has the place.

## Harvard (Cite Them Right)

Harvard has no single official standard: universities publish their own versions. If the user names a university guide, follow it; otherwise use the Cite Them Right pattern below and say in the summary line that it is that variant.

- Journal article: `<Surname>, <I.> and <Surname>, <I.> (<Year>) '<Article title>', *<Journal Title>*, <volume>(<issue>), pp. <first>–<last>. Available at: https://doi.org/<doi>.` (the "Available at" part only if a DOI is given; no accessed date is needed with a DOI.)
- Book: `<Surname>, <I.> (<Year>) *<Book title>*. <edition as an ordinal> edn. <Publisher>.` (edition only if given and not the first.)
- Authors in the reference list: list them all; three or more as `<Surname>, <I.>, <Surname>, <I.> and <Surname>, <I.>`.
- In-text: (Surname, Year); two authors (Surname and Surname, Year); three authors (Surname, Surname and Surname, Year); four or more (Surname et al., Year).

## IEEE

Numbered list headed "References", in the order of first citation in the text, not alphabetical. In text: [1], [2], [1], [3]; several sources as [1], [3]; a range as [1]–[3]. Initials come before the surname.

- Journal article: `[<n>] <I. I. Surname>, <I. I. Surname>, and <I. I. Surname>, "<Article title, sentence case>," *<Journal Title>*, vol. <n>, no. <n>, pp. <first>–<last>, <abbreviated month, only if given> <Year>, doi: <doi>.` (DOI only if given.) Two authors are joined by "and" with no comma.
- Book: `[<n>] <I. I. Surname>, *<Book Title>*, <edition as an ordinal> ed. <City, Country>: <Publisher>, <Year>.` (city and edition only if given.)
- Conference paper: `[<n>] <I. I. Surname>, "<Paper title>," in *<Proc. Conference Name>*, <Year>, pp. <first>–<last>.`
- Authors: list all up to six; for more than six, the first author followed by "et al.".
- Journal title abbreviations: IEEE abbreviates journal titles. Do not invent an abbreviation: keep the title as the user gave it and flag it if the target venue needs abbreviations.

## Vancouver (NLM / ICMJE)

Numbered list headed "References", in the order of first citation. In text: [1] or (1) or superscript, as the user's journal wants; keep what the user used.

- Journal article: `<n>. <Surname> <Initials>, <Surname> <Initials>. <Article title, sentence case>. <Journal title>. <Year>;<volume>(<issue>):<pages>. doi: <doi>` (issue and DOI only if given). NLM shortens the last page number to the digits that change (284-7 for 284 to 287).
- Book: `<n>. <Surname> <Initials>. <Book title>. <edition as an ordinal> ed. <Place>: <Publisher>; <Year>.` (edition and place only if given.)
- Authors: surname first, then initials with no full stops or spaces (Surname AB). NLM lists all authors; the ICMJE/NLM sample references list the first six followed by "et al.". Follow the target journal if the user names one; otherwise keep every author the user gave.
- Journal names: NLM abbreviations without full stops (as in the NLM Catalog). Do not invent abbreviations: keep the title as given and flag it.

## Checks that apply to every style

- One style throughout; the same punctuation, order and capitalisation pattern in every entry.
- Alphabetical styles (APA, MLA, Chicago, Harvard): entries sorted; every in-text author-year pair matches one entry. Numbered styles (IEEE, Vancouver): numbers run 1, 2, 3 in order of first citation with no gaps, and no number is cited that has no entry.
- DOI form: `https://doi.org/<doi>` in APA, MLA and Chicago; `Available at: https://doi.org/<doi>` in Harvard; `doi: <doi>` in IEEE and Vancouver. A DOI starts with `10.`; flag one that does not.
- Page range: first page before last page; flag a range that ends before it starts.
- Year: four digits, the same in the list and in the text. Flag a year in the future (it may be a forthcoming work); never supply a missing one.
- The same work listed twice (same first author and year and near-identical title): flag as a possible duplicate and keep both unless the user asks.
- Titles in a language other than the user's: leave them in the original language; keep diacritics.
